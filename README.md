## 👋 Welcome

**ChocoOps Cloud** is a production-grade manufacturing operations platform designed specifically for the complex needs of the luxury chocolate industry. 

Bridging the gap between traditional craftsmanship and modern DevOps, this system manages the entire lifecycle of chocolate production—from sourcing raw cacao beans to final product sales. It ensures quality consistency, optimizes inventory flow, and provides real-time insights for factory managers and artisans alike.

## 💎 Core Expertise & Modules

### 🏭 Production Orchestration
Orchestrates the delicate chocolate-making process. Tracks batches through **Roasting**, **Winnowing**, **Grinding**, **Conching**, and **Tempering** stages with precise parameter monitoring.

### 🛡️ Quality Assurance (QA)
Implements rigorous digital QC checkpoints. Sensory profiles, viscosity tests, and particle size analysis are recorded to ensure every bar meets the "Grand Cru" standard.

### 📦 Smart Inventory
Real-time tracking of raw ingredients (Cacao, Sugar, Milk Powder) and packaging materials. Automated low-stock alerts prevent production bottlenecks.

### 🔧 Predictive Maintenance
Monitors the health of critical machinery (Melangeurs, Tempering Units). Logs maintenance history and schedules preventive service to minimize downtime.

### 💰 Commerce & Sales
Integrated B2B/B2C sales dashboard with Stripe payment processing. Visualizes revenue trends, top-selling products, and customer acquisition metrics.

## 🚀 Quick Start

### Prerequisites
- **Node.js** >= 18
- **PostgreSQL** >= 14
- **npm** >= 9

### Installation

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/mebratu21-arch/choco-ops-cloud.git
    cd choco-ops-cloud
    ```

2.  **Install Dependencies**
    ```bash
    # Backend
    cd backend && npm install
    
    # Frontend
    cd ../frontend && npm install
    ```

3.  **Configure Environment**
    Create `.env` files in both directories using the provided examples.

4.  **Ignition**
    ```bash
    # Terminal 1: Backend
    cd backend && npm run dev
    
    # Terminal 2: Frontend
    cd frontend && npm run dev
    ```
