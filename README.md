## 🏛️ Project Architecture

**CocoaFlow AI** is a professional full-stack intelligent system designed to digitize and optimize chocolate factory operations. Inspired by real-world workflows at Max Brenner, it provides a seamless interface for inventory management, production lifecycle tracking, and automated quality control.

### 🔗 Core Pillars:
- **Scalable Backend**: Engineered with Node.js and Express for high-concurrency request handling.
- **Efficient Data Layer**: PostgreSQL (Neon) coupled with Knex.js for structured, high-performance data operations.
- **Responsive Frontend**: React-based SPA with Tailwind CSS for high-quality, professional aesthetics.
- **Intelligent Insights**: Google Gemini AI integration for real-time operational assistance.

## 🚀 Key Features & Capabilities

- **Real-time Inventory Monitor**: Threshold-based alerts and automated reordering logic for raw materials (Cocoa, Sugar, etc.).
- **Production Lifecycle Management**: Interactive Kanban system for tracking batches through *Mixing → Cooking → Cooling → Packaging*.
- **Integrated QC Audit**: Digital quality assurance ledger with real-time pass-rate analytics.
- **Gemini AI Assistant**: Specialized, role-aware AI that provides multilingual operational advice and safety alerts.
- **Secure RBAC**: Comprehensive Role-Based Access Control (Admin, Manager, Worker, Mechanic, Sales).

## 🔒 Security Standards

The system is built on a "Cisco Security First" philosophy:
- **JWT Authentication**: Secure, stateless user sessions.
- **API Protection**: Hardened endpoints with input validation and rate limiting.
- **Encrypted Transit**: Full SSL/TLS support for all data transfers.
- **Conventional Commits**: Strict adherence to the `feat/fix/refactor` commit standard for maintainable history.
